3.8節

1. 介紹統計方法：

  • 用例子列表的方式列出，每個例子分別計算。
  • 建議用清晰的方法列舉，以便理解各種統計的概念。

2. 統計記憶函數：

  • 列出各種可能性，計算總概率。
  • 統計範疇內列表，例如將S設為0、一個S設為多少，總和應等於1。

3.9 節

3. 例子說明 - 車型示例：

假設庫存裡有150%的車輛，都配備了側面網狀安全氣囊。找出這些車型的概率分佈。


4. 設計實驗方法：

丟硬幣模擬：

  • 丟4次硬幣每次的結果，作為車輛配備與否的可能性。
  • 計算各種情況下安全氣囊的數量。

5. 計算機率分佈：

用C(n, k)來表示n輛車中選取k輛有安全氣囊的組合。

提到若硬幣具有偏置（例如正面出現的概率較低），使用二項分佈計算。


3.9節下的題目解答

1. 製作表格示例：

  • 將所有可能結果列出。
  • 計算總概率並與給定問題對比。

2. 關於累積函數：

  • 解釋累積函數的圖形表示方法，特徵為曲線爬升。
  • 用積分表示累積機率。

Continuous Case

1. Continuous Case介紹：

  • 累積機率需用微積分計算。
  • 單點機率為0。

2. 計算示例 - 微積分應用：

  • 用面積表示機率，使用積分計算。

例題解析

例題1

題目：假設某溫度範圍內的機率密度函數。

f(x) = (1/9) * (x^2 + 2x + 1) for -1 <= x <= 2
計算：

核實總面積為1（使用積分）。計算特定範圍內的機率，如 P(0 ≤ x ≤ 1)。


例題2

題目：計算累積函數 F_X(x)。

F_X(x) = ∫ from -1 to x of f(t) dt
步驟：

使用積分計算累積函數，結果為：

F_X(x) = (1/9) * (x^3 / 3 + x^2 + x)
應用：

利用累積函數計算範圍機率，如 P(0 ≤ x ≤ 1) = F_X(1) - F_X(0)。
